# 📘 Excel MIS Practice Workbook

This project is a complete collection of my Microsoft Excel-based MIS dashboards, reports, and data visualizations. It showcases key Excel skills such as pivot tables, dynamic charts, KPI reports, and creative dashboards used in day-to-day business reporting.

---

## 📁 Files Included

| File Name                  | Description                                           |
|---------------------------|-------------------------------------------------------|
| `My MIS Practice Work.xlsm` | Macro-enabled Excel file containing all MIS sheets and dashboards |

---

## 📊 Key Features

- ✅ Pivot Tables for dynamic data summarization  
- 📈 Sales Trend, Ranking & Pareto Analysis  
- 📊 Advanced Charts – Speedometer, XY Scatter, See-Saw, etc.  
- 🧮 KPI Metrics with visual tracking  
- 📅 To-Do List and Task Reminder Dashboard  
- 🧠 Hyperlink-based navigation for easy access across sheets  

---

## 🛠️ Tools & Technologies

- **Microsoft Excel** – Data analysis and dashboard building  
- **VBA Macros** – Used only for navigation and small automation  
- **.XLSM File Format** – Macro-enabled Excel workbook

---

## 🧪 How to Use

1. Clone or download this repository to your local machine.  
2. Open the file `My MIS Practice Work.xlsm` in Microsoft Excel (2016 or later).  
3. Enable macros when prompted.  
4. Explore different sheets to see reports, dashboards, and charts in action.
